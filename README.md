# أخصائية غرس — 1.1.1

ابدأ من **[START-HERE-AR.md](START-HERE-AR.md)**. الحزمة مصدر كامل؛ ليس فيها APK مُجمّع.

تعالج النسخة إدراج الأسماء عند الصف 1001: الاسم الجديد يظهر مباشرة تحت العناوين، والأحدث في الأعلى. يتضمن Code.gs أمرًا لنقل البيانات الموجودة في الأسفل إلى الأعلى دون حذفها.

زر «جلب تعديلات الشيت» يستقبل تعديل المحاسب دون إرسال قيم الهاتف. تُرسل السجلات الجديدة أو المعدلة فقط في مسار الرفع. تبقى التعديلات المحلية غير المرسلة محفوظة، وتظهر الاختلافات للمراجعة إذا عدّل الطرفان الحقل نفسه. يحاول التطبيق الجلب كل 15 ثانية أثناء فتحه، ويبدأ محاولة رفع بعد الحفظ وعند عودة الشبكة؛ التنفيذ الخلفي يخضع لقيود Android.

رابط غرس مضمن، والدخول بكود الأخصائية فقط. الأكواد اليدوية ظاهرة في الشيت. الشعار وواجهة غرس والطلاب والجلسات والحضور والمنبهات موجودة.

## الملفات المهمة

- `google-apps-script/Code.gs`: استبدله في Apps Script الحالي وانشر إصدارًا جديدًا للنشر نفسه.
- `START-HERE-AR.md`: خطوات الشيت والتوقيع والبناء والنسخة الاحتياطية والتجربة.
- `tools/create-signing-key.ps1`: إنشاء مفتاح دائم مرة واحدة إن لم يكن لديك المفتاح القديم؛ لا يكتب فوق ملف موجود.
- `.github/workflows/main.yml`: يفحص المشروع ثم يبني نسختين موقعتين بنفس المفتاح الدائم؛ لا يوزع APK Debug.
- `CHANGELOG-1.1.1.md`: التغييرات.
- `docs/TESTING.md`: نتائج التحقق وحدوده.

## تحديث التطبيق

الإصدار `1.1.1`، رقم `5`. حزمة التحديث الأساسية `ps.ghars.sessions`. التحديث المباشر يتطلب الحزمة والتوقيع الموافقين للنسخة المثبتة. مفتاح جديد لا يستبدل مفتاحًا قديمًا مفقودًا.

إذا تعذر التحديث المباشر، يجهز سير العمل APK منفصلًا بمعرف `ps.ghars.sessions.transfer` واسم «أخصائية غرس · المزامنة»، لنقل ملف النسخة الاحتياطية مع إبقاء القديم مثبتًا. هذا تطبيق مستقل وليس تحديثًا مباشرًا. اتبع دليل النقل وتحقق من الأسماء والجلسات على الهاتف قبل اعتماد النسخة الجديدة.

لا تحذف تطبيق المعلمة أو تمسح بياناته لإجبار التثبيت. ملف APK القديم لا يحتوي مفتاح التوقيع الخاص.

## التحقق

نجحت **40 نتيجة Node و24 اختبار Java** محليًا. تم تجميع ملفات Java مقابل واجهات API 35 مع رموز موارد للفحص، والتحقق من صياغة Gradle وYAML وأوامر البناء. لم يُنفذ بناء APK كامل أو Android Lint أو تثبيت على هاتف هنا، ولم يُنشر السكربت في حساب المستخدم. يتولى GitHub فحوص البناء قبل إتاحة APK.

`SETUP-AR.md` ووثائق 1.1.0 وما قبله مراجع تاريخية؛ خطوات نشر النسخة الحالية في `START-HERE-AR.md`.
