# أخصائية غرس — الإصدار 1.1.0

تحديث للمشروع الأصلي 1.0.2: أكواد أخصائيات واضحة في Google Sheets، مساحات مستقلة، أكثر من هاتف لنفس المساحة، ومزامنة تعمل مع التخزين المحلي دون تعطيل الاستخدام عند انقطاع الإنترنت.

**ابدأ بدليل [SETUP-AR.md](SETUP-AR.md).** لا تحذف تطبيق المعلمة أو بياناته؛ صدّر نسخة احتياطية أولاً. الحزمة مصدر كامل، وليست APK جاهزاً أو تطبيقاً منشوراً.

## الملفات المهمة

- `google-apps-script/Code.gs`: كود الربط الذي تلصقه في مشروع Apps Script تابع لشيت جديد.
- `app/src/main/assets/sync-config.json`: ضع فيه رابط النشر `/exec` مرة واحدة قبل بناء APK، ليكتفي كل مستخدم بإدخال الكود.
- `.github/workflows/main.yml`: سير العمل الحالي للبناء والفحص؛ شغّله بنفس مفاتيح التوقيع السابقة.
- `SETUP-AR.md`: الخطوات التفصيلية للشيت، الأكواد، GitHub، أول رفع للأسماء، التجربة، والقيود.
- `docs/PRIVACY.md` و`docs/TESTING.md`: نطاق المشاركة والاختبارات التي نُفّذت فعلاً.

## ما الذي تغيّر؟

يحتفظ التطبيق بوظائف الطلاب والجلسات الجماعية والفردية والحضور والمنبهات والشعار وألوانه. الإضافة الجديدة شاشة دخول بالكود، زر خروج وتبديل الأخصائية، ذاكرة محلية منفصلة لكل مساحة، رفع الطلاب الحاليين بعد تأكيد صاحبة الكود، مزامنة الطلاب والجلسات والحضور والملاحظات بين الهواتف والشيت، ومراجعة تعارضات الحقول وتداخل المواعيد.

المحاسب يستخدم ثلاث أوراق فقط: الأخصائيات، طلاب غرس، وبيانات التطبيق التقنية. يعدّل الكود في نفس صف الأخصائية دون تغيير معرّف مساحتها أو أسماء طلابها. في ورقة الطلاب يكتب الكود والاسم وإجمالي جلسات النطق/السلوك، وتكمل الأخصائية الخطة والمواعيد. عدد الجلسات يُحسب من حضور جلسات مشتركة ذات معرّفات ثابتة، فلا يتضاعف بمجرد المزامنة على هاتفين.

المساحة المحفوظة تعمل دون إنترنت بعد أول دخول ناجح. التذكيرات الشخصية والصوت وقفل الجهاز محلية؛ الطلاب والجلسات والملاحظات مشتركة داخل الكود. ملف الشيت خاص بالمدرسة والمحاسب الموثوق، وإخفاء الورقة التقنية ليس حماية قراءة.

## الحفاظ على التحديث

`versionCode: 4`، `versionName: 1.1.0`، حزمة release `ps.ghars.sessions`، حزمة debug `ps.ghars.sessions.debug`، وتخزين الإصدار القديم `state.ghl` ومفتاحه وصيغته باقية. **قبول APK كتحديث يتطلب توقيع النسخة المثبّتة نفسه**؛ لا تكفي مطابقة اسم الأيقونة. مفاتيح debug المؤقتة في GitHub قد تختلف؛ راجع الدليل قبل التثبيت على هاتف المعلمة.

## الاختبارات والبناء

```sh
node --test tests/*.test.js
./gradlew --no-daemon lintDebug testDebugUnitTest assembleDebug
```

نجحت 34 نتيجة اختبار Node محلياً. اختبارات Java مرفقة لتشغيلها في GitHub. لم يتوفر تنزيل Gradle أو متصفح Chromium في بيئة التجهيز، لذلك لم يُبنَ APK هنا ولم تُنفذ معاينة رسومية أو تجربة هاتف فعلي للنسخة الجديدة. `tests/preview.cjs` تجربة مرئية اختيارية تتطلب Playwright وChromium مثبتين، وليست ضمن اختبارات Node الاعتيادية.

وثائق `UPDATE-1.0.1.md` و`UPDATE-1.0.2.md` سجل تاريخي للإصدارات السابقة، وليست خطوات نشر أو نتائج اختبار هذه النسخة.
