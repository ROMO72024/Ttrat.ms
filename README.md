# غرس — تحديث يستهدف APK المرفق

ابدأ بـ [START-HERE-AR.md](START-HERE-AR.md).

ملف المستخدم الأصلي: `ps.ghars.sessions.debug`، الإصدار `1.0.2-debug` / `3`.
المصدر الحالي: المعرف نفسه، الإصدار `1.1.1` / `5`، مع إصلاحات مزامنة الشيت.

**إخراج APK قابل للتحديث يتطلب مفتاح التوقيع الأصلي. لم يُرفق هذا المفتاح، والحزمة ليست APK جاهزًا.**

سير GitHub يتحقق من بصمة شهادة المفتاح، ثم من هوية APK المبني وشهادته ورقم إصداره. يتوقف إذا اختلفت، ولا ينشئ مفتاحًا بديلًا.

- `tools/legacy-apk.json`: بيانات الفحص الحقيقي للملف المرفق.
- `tools/check-original-key.ps1`: فحص ملف Debug keystore موجود، وتصدير إعداداته اختياريًا إذا طابقت الشهادة.
- `tools/verify_legacy_update.py`: فحوص مطابقة الشهادة ومخرجات Android SDK.
- `docs/SHEETS-SYNC-AR.md`: ربط الشيت، إصلاح 20 إلى 10، والأسماء في الأعلى.

لم تتغير Java أو الأصول أو Code.gs عن مصدر 1.1.1 المختبر سابقًا. الوثائق التاريخية لتغييرات الإصدارات تبقى سجلًا؛ تعليمات البناء المعتمدة هنا في START-HERE-AR.md.
