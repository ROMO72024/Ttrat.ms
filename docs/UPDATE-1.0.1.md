# تحديث غرس 1.0.1

## التغييران المطلوبان

1. **منبّه عند بدء الجلسة تلقائياً:** يظل التذكير المسبق في الوقت الذي تختارينه، ويضاف منبّه مستقل عند بداية الجلسة. مثال: جلسة 10:00 مع تذكير قبل نصف ساعة ترن في 09:30 ثم 10:00. وإذا لم تحددي تذكيراً مسبقاً، ترن عند 10:00 فقط. صفر دقيقة يعطي منبهاً واحداً عند البداية.
2. **حقول جديدة فارغة:** لا توجد أرقام جاهزة مثل 12 أو 2، ولا مدة أو وقت بداية أو مهلة تذكير أو عدد أسابيع مفروض. التاريخ فقط يبدأ بتاريخ اليوم. النوع والفترة والحضور وأيام التكرار تختارينها بنفسك. البيانات الفعلية للسجلات السابقة تبقى عند تعديلها.

منبّه البداية يعمل لكل جلسة مجدولة محفوظة، بما فيها الجلسات الجماعية والمتكررة. إتمام الجلسة أو إلغاؤها يلغي تنبيهاتها القادمة. لم تتغير أرصدة الطلاب أو الملاحظات أو صيغة النسخ الاحتياطية.

## تثبيت التحديث

- إذا ثبّتِّ **Ghars-Preview.apk** المرفق سابقاً، ثبتي **Ghars-Update-1.0.1.apk** فوقه مباشرة. التحديث يحمل هوية التطبيق ومفتاح التوقيع السابقين؛ لا يلزم حذف التطبيق.
- إذا بنيتِ التطبيق من GitHub، استخدمي ملفات المشروع الجديدة، وابني نفس نوع نسختك السابقة بمفتاح التوقيع نفسه. APK المرفق هنا يحدّث «غرس · معاينة» فقط؛ لا يحدّث تطبيق GitHub ذي الهوية المختلفة.
- احتفظي بنسخة احتياطية مشفرة قبل تحديث التطبيق. بعد التثبيت افتحي غرس مرة واحدة لإعادة جدولة المنبهات، ثم جرّبي جلسة قريبة بتذكير مسبق وتحققي من الرنين عند بدايتها.

المشروع المحدث يحمل versionCode 2 وversionName 1.0.1. تظل متطلبات أذونات أندرويد والصوت والبطارية كما كانت في النسخة السابقة.
