# تحديث أخصائية غرس 1.0.2

أصبح اسم التطبيق على الهاتف وفي الواجهة **أخصائية غرس**.

## إصلاح البناء

أُصلح خطأ `UnspecifiedRegisterReceiverFlag` بإزالة بثّ إغلاق شاشة المنبّه الداخلي. تغلق الخدمة شاشات المنبّه المفتوحة مباشرة عند توقفها، عبر مراجع ضعيفة لا تحتفظ بالشاشات بعد تدميرها. يعمل ذلك داخل عملية التطبيق على جميع إصداراته المدعومة، ولا يحتاج إلى مستقبِل أو إذن إضافي. بقي فحص Lint مفعّلاً دون إضافة ملف لإخفاء أخطاء سابقة.

مرجع متطلبات التسجيل: [توثيق أندرويد الرسمي](https://developer.android.com/about/versions/14/behavior-changes-14#runtime-receivers-exported).

تتضمن النسخة التذكير التلقائي عند بدء كل جلسة، إضافة إلى التذكير المسبق الاختياري. وتبقى حقول الإضافة فارغة عدا التاريخ، مع الحفاظ على بيانات السجلات القديمة عند تعديلها.

## الرفع إلى مستودع GitHub الحالي

1. فكّي ضغط `Ghars-Android-v1.0.2.zip`.
2. من صفحة **Code** في المستودع، اختاري **Add file → Upload files**.
3. ارفعي محتويات المجلد المفكوك إلى جذر المستودع لاستبدال الملفات السابقة، ثم اختاري **Commit changes**. لا ترفعي ملف ZIP نفسه ولا تضعي المشروع داخل مجلد إضافي.
4. إذا كان ملف `.github/workflows/main.yml` الذي أنشأتِه سابقاً موجوداً، اتركيه؛ لا تحتاجين إنشاء ملف بناء ثانٍ. المجلد `.github` المرفق يلزم فقط إذا لم يكن عندك ملف بناء.
5. افتحي **Actions → Build APK** وانتظري نجاح التشغيل الجديد. أعيدي البناء بعد رفع الملفات؛ زر إعادة تشغيل العملية القديمة يستخدم الشيفرة القديمة.
6. حمّلي `ghars-debug-apk` من **Artifacts** وفكّي ضغطه للحصول على `app-debug.apk`.

## APK الجاهز

`Ghars-Update-1.0.2.apk` نسخة المعاينة المحلية، بمعرّف `ps.ghars.sessions.preview` ورقم إصدار 3. تحمل نفس توقيع ملف المعاينة الذي سلّمناه سابقاً ويمكن تثبيتها فوقه. نسخة GitHub بمعرّف مختلف؛ لن تستبدل نسخة المعاينة. لنقل البيانات بينهما استخدمي النسخة الاحتياطية المشفّرة من إعدادات التطبيق.

تفاصيل الفحوص الفعلية مسجلة في `docs/TESTING.md`.
