# تحقق إعداد التحديث الخاص بالملف المرفق

- تحقق Android apksig 8.7.3 من سلامة توقيع APK المرفق بنجاح، دون أخطاء؛ تم استخراج البصمة الفعلية.
- مقارنة ملفات الواجهة داخل APK بمصدر 1.0.2: تطابق app.js وcore.js وindex.html وstyle.css وlogo.png.
- تغييرات هذه الحزمة محصورة في إعداد البناء وفحص التوقيع والتوثيق. ملفات Java والأصول والخادم مطابقة بايتًا لنسخة 1.1.1 التي اجتازت 40 اختبار Node و24 اختبار JUnit سابقًا.
- اختبارات Python لبوابة التحديث تقبل الهوية والشهادة المطابقتين ورقمًا أعلى، وترفض الحزمة المختلفة والمفتاح المختلف والإصدار غير الأعلى وتقارير التحقق الناقصة والتوقيع الإضافي.
- فُحص YAML وأوامر shell وصياغة Gradle. لا تعادل هذه الفحوص بناء APK أو تجربة تثبيت.
- لم يُشغّل PowerShell على Windows. لم يُبنَ APK جديد ولم يُجرّب تثبيت أو استعادة بيانات المعلمة.
