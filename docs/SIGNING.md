# توقيع تحديث النسخة المرفقة

تعليمات البناء الحالية كاملة في [START-HERE-AR.md](../START-HERE-AR.md).

لا تُنشئ مفتاحًا جديدًا لتحديث app-debug.apk الأصلي. هذا المسار يطلب شهادة SHA-256 المحددة في `tools/legacy-apk.json` ومفتاحها الخاص. لا يمكن للشهادة العامة وحدها توقيع تحديث.

Release هنا يحمل معرّف `ps.ghars.sessions.debug` ليتطابق مع المثبت. ما دام المفتاح الصحيح موجودًا، يمكن استخدامه للتوقيع مع رقم إصدار أعلى. تغيير اسم APK أو شعار التطبيق أو namespace لا يحل اختلاف التوقيع.

المفتاح المطلوب في هذه الحالة Debug: الاسم الافتراضي `androiddebugkey` وكلمتا المرور الافتراضيتان `android`، لكن يجب أولًا التحقق من البصمة. آلاف مفاتيح Debug تحمل الاسم وكلمة المرور نفسيهما وتختلف مفاتيحها وشهاداتها.

[توثيق Android](https://developer.android.com/studio/publish/app-signing).
